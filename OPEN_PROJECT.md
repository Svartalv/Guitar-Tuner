# Open the Project

The Xcode project has been created! To open it:

## Option 1: Double-click
Double-click `Guitar Tuner.xcodeproj` in Finder

## Option 2: Command line
```bash
open "Guitar Tuner.xcodeproj"
```

## Option 3: From Xcode
1. Open Xcode
2. File → Open
3. Navigate to this directory
4. Select `Guitar Tuner.xcodeproj`

## After Opening

1. **Select the scheme**: Choose "Guitar Tuner" and "My Mac" as destination
2. **Build**: Press ⌘B to build
3. **Run**: Press ⌘R to run
4. **Grant microphone permission** when prompted

The project should build and run on macOS!
